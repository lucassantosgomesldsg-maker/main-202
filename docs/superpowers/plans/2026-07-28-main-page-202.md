# Main page da 202 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir a página única de `202lab.com.br` — uma tela sem scroll, preta, com a logo "202" entrando com movimento, oneliner bilíngue no canto inferior esquerdo e contato apontando para o Instagram.

**Architecture:** Next.js App Router com uma única rota. `app/page.tsx` é um Client Component (a página inteira depende do estado de idioma). A logo é SVG inline, com os três glifos como `<path>` independentes, o que permite animá-los separadamente. Cada candidato a motion é um componente fino que envolve `<Logo202/>` e aplica seu próprio CSS Module — trocar o vencedor é trocar um import.

**Tech Stack:** Next.js (App Router, TypeScript), React 19, CSS puro + CSS Modules (sem Tailwind), `next/font/google` (Fraunces + IBM Plex Mono), Vitest + Testing Library para lógica, Playwright para as regras de layout.

**Spec:** `docs/superpowers/specs/2026-07-28-main-page-202-design.md` — leia antes de começar.

## Global Constraints

- **Nenhum scroll, em nenhum viewport.** Usar `100dvh`, nunca `100vh`.
- **Copy verbatim.** Os textos da §4 do spec não podem ser parafraseados, nem ter pontuação alterada. Eles vivem só em `lib/copy.ts`.
- **Um único ponto verde na página**, e ele pertence à logo. O oneliner termina com ponto branco comum.
- **Tokens de cor sem alteração:** `--preto-202 #0A0A0A`, `--padrao-202020 #141414`, `--branco-202 #FFFFFF`, `--cinza-texto #8B8B85`, `--verde-sinal #C6FF3E`, `--cinza-linha #262626`.
- **Margens:** `3rem` no desktop, `1.5rem` abaixo de 720px.
- **Mono-labels:** IBM Plex Mono, 12px, `text-transform: uppercase`, `letter-spacing: 0.1em`, cor `--cinza-texto`.
- **The Seasons não é usada.** Nenhum `@font-face` dela entra no projeto.
- **`prefers-reduced-motion: reduce` desliga toda animação**, incluindo o pulso do ponto verde.
- **Sem analytics, sem cookies, sem rastreamento.** Nenhuma biblioteca que faça requisição a terceiros em runtime.
- **Idioma inicial é sempre português.** Não detectar idioma do navegador.
- **Repo de origem é somente-leitura.** Nada em `C:\Users\Lucas\202` pode ser modificado.

// Extrai os três glifos do SVG-pôster da 202 e gera lib/logo-paths.ts.
// Rodar de novo só se o SVG de origem mudar.
import { readFileSync, writeFileSync } from "node:fs";

const ORIGEM = "public/202_Branco.svg";
const DESTINO = "lib/logo-paths.ts";

// viewBox justo aos glifos. Medido no navegador via getBBox() — ver Task 4, Step 2.
// Valor inicial: o retângulo de clip do SVG original (61, 527, 664, 440).
const VIEWBOX = process.env.LOGO_VIEWBOX ?? "61 527 664 440";

const svg = readFileSync(ORIGEM, "utf8");

const grupo = /<g transform="(matrix\([^"]+\))"/.exec(svg);
if (!grupo) throw new Error("Não achei o transform do grupo no SVG de origem.");

const glifos = [
  ...svg.matchAll(
    /<g transform="(translate\([^"]+\))"[^>]*>\s*<path[^>]*\sd="([^"]+)"/g,
  ),
].map(([, transform, d]) => ({ transform, d }));

if (glifos.length !== 3) {
  throw new Error(`Esperava 3 glifos, achei ${glifos.length}.`);
}

const ts = `// GERADO por scripts/extrair-logo.mjs — não editar à mão.
// Origem: visual_assets/Raw_Images/202_Branco.svg (repo da trilha).

export const LOGO_VIEWBOX = ${JSON.stringify(VIEWBOX)};
export const LOGO_GRUPO_TRANSFORM = ${JSON.stringify(grupo[1])};

export const LOGO_GLIFOS = ${JSON.stringify(glifos, null, 2)} as const;
`;

writeFileSync(DESTINO, ts, "utf8");
console.log(`OK — 3 glifos escritos em ${DESTINO}`);
```

Requisitos idênticos para os três (repetidos aqui de propósito — cada subagente lê só o seu bloco):

- O componente envolve `<Logo202 />` e adiciona só o que a sua animação precisa.
- Raiz com `data-motion="A|B|C"` e `data-estatico={String(!!estatico)}`.
- Com `estatico`, o estado final aparece de imediato: nenhuma animação, nenhum flash.
- Duração total ≤ `DURACAO_MAXIMA_MS` (1800 ms).
- O ponto verde (`[data-ponto]`) é o **último** elemento a aparecer, sempre.
- Animação em CSS puro (`@keyframes`), sem biblioteca. Se for impossível, parar e reportar em vez de instalar uma dependência.
- Só animar `transform`, `opacity`, `clip-path` e `stroke-dashoffset` — nada que force relayout.
- `@media (prefers-reduced-motion: reduce)` no CSS Module do candidato, deixando tudo no estado final.
- Nenhum arquivo fora de `components/motion/Motion<X>.tsx` e `Motion<X>.module.css` pode ser tocado.

/* MotionB.module.css */
.palco {
  position: relative;
  display: grid;
  place-items: center;
}

/* Estado inicial: os glifos escondidos, o ponto apagado. */
.logo :global([data-glifo]) {
  opacity: 0;
  transform: translateY(28%);
}
.logo :global([data-ponto]) {
  opacity: 0;
}

  animation-delay: 120ms;
}
.palco[data-estatico="false"] .logo :global([data-glifo][data-indice="2"]) {
  animation-delay: 240ms;
}
.palco[data-estatico="false"] .logo :global([data-ponto]) {
  animation: acender 380ms ease-out 980ms both; /* 980 + 380 = 1360ms < 1800ms */
}

/* Estado final: quando estático, tudo já montado, sem animar. */
.palco[data-estatico="true"] .logo :global([data-glifo]),
.palco[data-estatico="true"] .logo :global([data-ponto]) {
  opacity: 1;
  transform: none;
}

@keyframes subir {
  from { opacity: 0; transform: translateY(28%); }
  to   { opacity: 1; transform: none; }
}

@keyframes acender {
  from { opacity: 0; transform: scale(0.4); }
  to   { opacity: 1; transform: none; }
}

@media (prefers-reduced-motion: reduce) {
  .logo :global([data-glifo]),
  .logo :global([data-ponto]) {
    opacity: 1;
    transform: none;
    animation: none;
  }
}

Dois detalhes que valem para os três: `:global()` é obrigatório para alcançar os atributos
`data-*` que o `Logo202` gera, porque CSS Modules só renomeia classes — e o estado final tem
que estar escrito explicitamente, não só implícito no fim da animação, senão o modo estático
mostra a logo invisível.

**Subagente A — linhas construtivas.** Uma hairline horizontal e uma vertical (1px, `--cinza-linha`) crescem do centro até atravessar a tela inteira. Elas se cruzam sobre a logo, e os glifos são revelados a partir da interseção via `clip-path` que se abre. As linhas então recuam e somem; o ponto verde acende no fim. É o elemento gráfico nº3 do `design.md`. As linhas são `position: absolute` dentro da raiz, com `aria-hidden="true"`.

**Subagente B — revelação vertical por glifo.** Cada `[data-glifo]` sobe de trás de uma máscara. Como são elementos SVG, use `clip-path` no `<g>` ou uma máscara sobre cada glifo — não `overflow: hidden`, que não recorta filhos de SVG de forma confiável. Atraso escalonado de ~120 ms entre os três, na ordem `data-indice` 0, 1, 2. O ponto verde entra depois do terceiro glifo.

**Subagente C — traço desenhando o contorno.** Aplicar `fill: none; stroke: var(--branco-202); stroke-width: 2` nos paths, com `stroke-dasharray`/`stroke-dashoffset` animando de "invisível" a "desenhado". O comprimento de cada path não é conhecido de antemão: use um valor grande fixo (ex.: `4000`) e ajuste até o traço percorrer o contorno inteiro sem sobrar nem faltar. Depois de desenhado, o preenchimento branco aparece via transição de `fill-opacity`, e o stroke some. O ponto verde é o último.

"use client";

import { useEffect, useState } from "react";

const CHAVE = "202:motion";

/** Guarda de módulo: o StrictMode monta duas vezes, mas esta carga da página
 *  só pode decidir uma vez. Um reload zera isto; o sessionStorage não. */
let decididoNestaCarga = false;

/** true quando a animação já rodou nesta sessão do navegador — ou seja,
 *  quando a logo deve aparecer já montada. Começa em false para que o
 *  HTML do servidor e o primeiro render do cliente sejam idênticos. */
export function usaMotionUmaVez(): boolean {
  const [jaRodou, setJaRodou] = useState(false);

  useEffect(() => {
    if (decididoNestaCarga) return;
    decididoNestaCarga = true;

    if (window.sessionStorage.getItem(CHAVE) === "1") {
      setJaRodou(true);
    } else {
      window.sessionStorage.setItem(CHAVE, "1");
    }
  }, []);

  return jaRodou;
}
```
